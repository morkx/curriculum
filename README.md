# Curriculum · Sebastian Valenzuela

Sitio personal con mi curriculum: perfil, habilidades, proyectos, experiencia y formación.

**Ver en línea:** https://morkx.github.io/curriculum/

## Estructura

- `index.html`: todo el contenido del sitio.
- `css/style.css`: estilos propios (sobre Bootstrap 3).
- `js/main.js`: menú y navegación.
- `img/about.jpg`: foto de perfil.
- `files/svalenzuela_CV_2026.pdf`: CV descargable.

## Ver en local

```bash
python3 -m http.server 8000
# abrir http://localhost:8000
```

## Publicación

Se publica con GitHub Pages desde la rama `master`. No necesita servidor: el contacto es por correo (`mailto:`), sin formulario PHP.

Diseño basado en una plantilla de [TemplateWire](http://www.templatewire.com).
